How sign-in works

Your session is an opaque token in an HttpOnly, SameSite=Strict cookie. Page scripts cannot read it, so a cross-site script injection has no token to steal, and the browser will not attach it to requests started by another site.

Every state-changing call additionally carries a CSRF token that only our own pages can read. Sessions are rows in the database, so you can revoke any of them instantly from Account.
